# 💼 RetailPulse – Supermarket Sales Intelligence

A Power BI dashboard showcasing insights from 100,000 rows of transactional supermarket data. Designed for real-time business monitoring, category trends, and regional performance.

## 📊 Dashboard Highlights
- 📈 Monthly Sales Trend
- 📍 Regional Sales vs Profit
- 🧃 Category-Wise Sales Distribution
- 🧮 KPI Cards (Sales, Profit, Orders, Avg Sales)
- 🎛 Interactive Filters

## ⚙️ Built With
- Power BI Desktop
- Custom DAX Measures
- Excel-based data cleanup
- City Park Theme (customized)

## 📌 Key Learnings
- Leveraged DAX for KPI logic
- Enhanced visual storytelling with slicers
- Applied business reasoning to sales cycles
